1. 寒暄
你好呀！今天想吃水果吗？
2. 标题页讲解
开场白：开始今天的课啦！请翻到标题页，我们学绘本《Fruit》，一起认识水果的英语说法～生词讲解：“Fruit” 是 “水果”，跟我读 2 遍：Fruit，水果～提问：看到 “Fruit”，你想到什么水果呀？
3. 正文逐页讲解
第 1 页（内容：This is a cherry.）
模式：第三种步骤：提示：请翻到有红色小果子的这一页～提问：这页图片里的水果是什么颜色呀？讲解：对啦！课文是 “This is a cherry.”（这是一颗樱桃）。“cherry” 是 “樱桃”，核心语法：“This is + 东西” 就是 “这是……”。
第 2 页（内容：This is a pear.）
模式：第一种步骤：提示：翻到下一页～朗读：我读 2 遍：This is a pear. This is a pear.讲解：“pear” 是 “梨”，用 “This is + 水果名” 说 “这是某种水果”。提问：你喜欢吃 pear 吗？
第 3 页（内容：This is a banana.）
模式：第二种步骤：提示：翻下一页，你来读一遍课文吧～纠正：“banana” 这样读哦，再试一次～讲解：“banana” 是 “香蕉”，长长的、黄色的就是 banana。提问：你吃过 banana 吗？
第 4 页（内容：This is a tomato.）
模式：第三种步骤：提示：翻到有红色圆果子的页～提问：这页的水果你认识吗？讲解：课文是 “This is a tomato.”（这是一颗番茄）。“tomato” 是 “番茄”，也属于水果哦。
第 5 页（内容：This is an apple.）
模式：第一种步骤：提示：翻下一页～朗读：我读 2 遍：This is an apple. This is an apple.讲解：“apple” 是 “苹果”，红色或绿色的 apple 很常见。提问：你爱吃 apple 吗？
第 6 页（内容：This is an orange.）
模式：第二种步骤：提示：翻下一页，你来读课文～纠正：跟着我读：orange，再试一次～讲解：“orange” 是 “橙子”，酸酸甜甜的 orange。提问：orange 是什么颜色呀？
第 7 页（内容：This is a lemon.）
模式：第三种步骤：提示：翻到有黄色果子的页～提问：这页的水果看起来酸不酸呀？讲解：对啦！课文是 “This is a lemon.”（这是一颗柠檬）。“lemon” 是 “柠檬”，味道酸酸的。
第 8 页（内容：This is fruit.）
模式：第一种步骤：提示：翻到最后一页～朗读：我读 2 遍：This is fruit. This is fruit.讲解：这句话是 “这是水果”，前面学的所有果子都叫 fruit。提问：你最喜欢今天学的哪种 fruit？
4. 课堂总结
今天学了 8 个词：cherry（樱桃）、pear（梨）、banana（香蕉）、tomato（番茄）、apple（苹果）、orange（橙子）、lemon（柠檬）、fruit（水果）。核心语法：“This is + 名词”=“这是……”。我们一起读所有句子：This is a cherry... This is fruit.
5. 宣布下课
今天的课结束啦！回家和家人说说今天学的水果英语哦～下课！
