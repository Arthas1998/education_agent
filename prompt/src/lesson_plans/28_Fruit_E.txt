1. Greetings
Hello. Would you like some fruit today?
2. Title Page Explanation
Opening: Class starts now. Please turn to the title page. We will learn the picture book "Fruit" and get to know the English words for fruits together.New Word Explanation: "Fruit" means "水果". Repeat after me twice: Fruit, 水果.Question: What fruits do you think of when you see "Fruit"?
3. Page-by-Page Explanation of the Main Text
Page 1 (Content: This is a cherry.)
Mode: ThirdSteps:Prompt: Please turn to the page with small red fruits.Question: What color are the fruits in the picture on this page?Explanation: That's right. The text is "This is a cherry." "Cherry" means "樱桃". Core grammar: "This is + something" translates to "这是……".
Page 2 (Content: This is a pear.)
Mode: FirstSteps:Prompt: Turn to the next page.Reading: I will read twice: This is a pear. This is a pear.Explanation: "Pear" means "梨". Use "This is + fruit name" to say "这是某种水果".Question: Do you like eating pears?
Page 3 (Content: This is a banana.)
Mode: SecondSteps:Prompt: Turn to the next page. Please read the text once.Correction: This is how you pronounce "banana". Try again.Explanation: "Banana" means "香蕉". The long yellow one is a banana.Question: Have you eaten bananas?
Page 4 (Content: This is a tomato.)
Mode: ThirdSteps:Prompt: Turn to the page with round red fruits.Question: Do you know the fruit on this page?Explanation: The text is "This is a tomato." "Tomato" means "番茄" and it is also a type of fruit.
Page 5 (Content: This is an apple.)
Mode: FirstSteps:Prompt: Turn to the next page.Reading: I will read twice: This is an apple. This is an apple.Explanation: "Apple" means "苹果". Red or green apples are very common.Question: Do you like eating apples?
Page 6 (Content: This is an orange.)
Mode: SecondSteps:Prompt: Turn to the next page. Please read the text.Correction: Repeat after me: orange. Try again.Explanation: "Orange" means "橙子". Oranges are sour and sweet.Question: What color is an orange?
Page 7 (Content: This is a lemon.)
Mode: ThirdSteps:Prompt: Turn to the page with yellow fruits.Question: Does the fruit on this page look sour?Explanation: That's right. The text is "This is a lemon." "Lemon" means "柠檬". It tastes sour.
Page 8 (Content: This is fruit.)
Mode: FirstSteps:Prompt: Turn to the last page.Reading: I will read twice: This is fruit. This is fruit.Explanation: This sentence means "这是水果". All the fruits we learned earlier are called fruit.Question: Which fruit we learned today do you like best?
4. Class Summary
Today we learned 8 words: cherry (樱桃), pear (梨), banana (香蕉), tomato (番茄), apple (苹果), orange (橙子), lemon (柠檬), fruit (水果). Core grammar: "This is + noun" translates to "这是……". Let's read all the sentences together: This is a cherry... This is fruit.
5. Closing the Class
Class is over today. Tell your family about the fruit English words we learned today. Class dismissed!
